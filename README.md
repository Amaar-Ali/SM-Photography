# Indian Album Unfolding

BUILD A COMPLETELY NEW WEBSITE FROM SCRATCH

Create a completely new website for:

SM Photography

A wedding photography and cinematography brand based in Delhi.

This is a from-scratch build.

There is no existing design system to preserve.

Do not imitate generic wedding-photographer websites.

Do not create a SaaS-style layout.

Do not create a generic "luxury photography" landing page.

Build a distinctive modern Indian wedding photography experience with its own visual language, storytelling system, interactions, animations and art direction.

THE CENTRAL CREATIVE CONCEPT

THE INDIAN WEDDING ALBUM — REIMAGINED FOR THE WEB

The website should feel like you've taken the physical experience of opening an extraordinary Indian wedding album and turned it into an interactive digital experience.

Think:

Indian wedding invitation

Mughal / Rajasthani architectural geometry

Indian textiles

mehndi linework

marigold / sindoor / saffron color

contemporary Indian fashion editorials

cinematic wedding photography

modern web interaction design

The result should feel:

CULTURAL

CINEMATIC

TACTILE

BOLD

EDITORIAL

EMOTIONAL

PREMIUM

but still modern and extremely usable.

ABSOLUTELY DO NOT DO THIS

Do not make:

 generic beige luxury website

 generic black-and-white photographer website

 generic white background + serif heading website

 wedding invitation website from 2015

 excessive gold

 excessive maroon

 cheesy Indian motifs

 random mandalas

The website should feel like modern Indian design, not "Indian decoration."
