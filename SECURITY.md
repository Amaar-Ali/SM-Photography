# Security Policy

## Supported versions

Only the latest version on `main` is supported.

## Reporting a vulnerability

If you discover a security issue in this website:

1. Email **amaaralisyed2011@gmail.com**, or
2. Open a **private** GitHub security advisory if available

Do not file a public issue with exploit details.

Please include:

- A clear description of the issue
- Steps to reproduce
- Potential impact

Do not disclose the vulnerability publicly until it has been addressed.

We will acknowledge reports as soon as practical and keep you updated on progress.
